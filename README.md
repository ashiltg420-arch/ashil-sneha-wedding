# Ashil & Sneha Wedding Invitation

Floral Hindu-style animated wedding e-invitation for Ashil & Sneha.

## GitHub Pages
Enable **Settings → Pages → Deploy from a branch → main → / (root)**.

The guest-wishes form uses browser localStorage, so entries are stored on the visitor's device. A shared public guestbook needs a database/backend service.
